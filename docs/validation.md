## 수행하지 못한 화면 검사

최종 HTML 생성 후에도 Computer Use의 브라우저 호스트가 `The browser access host is unavailable`을 반환했습니다. 이전 native 브라우저 접근도 현재 URL을 확인하지 못해 중단했습니다. 따라서 **HTML의 실제 브라우저 화면, 검색·선택·페이지 이동, 차트 편집·인쇄의 직접 조작 검증은 수행하지 못했습니다**. 소스 검토·빌드·데이터 일치·단일 파일 내보내기 검증과 실제 화면 검증을 구분합니다. PPT는 별도로 PowerPoint 렌더링을 통해 확인했습니다.

## 해석의 한계

- 현재 구성기업·현재 GICS를 과거에 적용해 생존편향이 남습니다. 문서 확보와 완결 OOS 평가의 기업 수가 다르고, 같은 기업도 모든 분기에 관측되지 않습니다.
- 형성 시점은 40개 분기, 수익률 OOS 평가는 26개 분기입니다. FOMC 원문 81건 중 분기별 최신 40건을 사용합니다. 기업 행 수를 독립적인 거시 표본 수로 계산하지 않습니다.
- LM 어조·키워드 주제는 사람 정답으로 검증한 경제 방향 지표가 아닙니다. 고정 수업용 사전 아카이브를 과거 전체에 적용했으며 당시의 사전·소프트웨어 버전까지 재현한 실시간 운용 실험은 아닙니다.
- FinBERT는 같은 문장 표본의 점수 일치도 비교입니다. 정확도·투자성과 우위의 증거가 아니며 중립을 불확실성과 동일시하지 않습니다.
- 주제 제거는 기업·FOMC·상호작용의 해당 주제를 함께 제외합니다. FOMC만의 기여나 인과적 섹터 민감도를 뜻하지 않습니다.
- 괴리 축소와 다음 어조의 예측은 경제·실적 전망의 정확성 및 투자 수익률과 별개입니다. 다중 비교 보정과 독립된 최종 검증 표본은 후속 작업입니다.
- 거래비용은 거래금액당 10bp 시나리오이며 대차료·조달비용·시장충격을 포함하지 않습니다.
- 보존한 파일럿과 전수 결과의 차이에는 표본 확대, 원문 교정, 기업 구성, 상대적 Ridge 규제 강도와 포트폴리오 평가기간 차이가 함께 들어갑니다. 독립적인 재현 실험이나 순수한 표본 확대 효과로 해석하지 않습니다.

## 재검증 명령

```powershell
python -m pytest -q
python -m compileall -q src scripts
python scripts/validate_results.py  # 본인의 허가된 자료로 만든 data/private/full 필요
python scripts/verify_outputs.py   # 공개 산출물 검사; private가 있으면 추가 재계산
```

원문 수정이나 분석 재실행 이후에는 README·HTML·결과 PPT를 함께 다시 생성해야 합니다. 동결 CSV가 분석 입력과 다르면 최종 HTML 생성과 산출물 검사가 실패하도록 구성했습니다.
