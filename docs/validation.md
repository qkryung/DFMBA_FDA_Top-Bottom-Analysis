## 수행하지 못한 화면 검사

이 환경의 Computer Use 도구가 Windows 브라우저의 현재 URL을 확인하지 못해 정책상 중단되었습니다. 따라서 **HTML을 실제 브라우저에서 띄운 화면 검사와 주제·섹터 선택, 차트 편집, 인쇄 동작의 직접 조작 검증은 수행하지 못했습니다**. 코드를 검토하고 빌드·데이터·내보내기를 검증한 것과 브라우저 화면 검증을 구분합니다. PPT 화면은 별도로 PowerPoint 렌더링을 통해 확인했습니다.

## 해석의 한계

- 현재 구성종목에서 선택한 33개 기업을 과거에 적용했습니다. 생존편향·현재 GICS 고정 적용·선택 표본 문제가 남습니다.
- 투자 패널은 40개 분기, 수익률 OOS 평가는 26개 분기입니다. FOMC 원문 80건 중 분기별 최신 40건을 사용합니다. 기업 행 수를 독립적인 거시 표본 수로 계산하지 않습니다.
- 키워드 주제와 LM 어조는 사람 정답으로 검증한 경제 방향 지표가 아닙니다. FinBERT 비교도 방법 간 일치도이며 정확도나 수익률 우위의 증거가 아닙니다.
- 괴리 축소와 다음 어조의 예측은 경제·실적 전망의 정확성 및 투자 수익률과 별개입니다. 다중 비교 보정과 독립된 최종 검증 표본은 후속 작업입니다.
- 비용 차감 롱숏은 거래금액당 10bp 시나리오이며 대차료·조달비용·시장충격을 포함하지 않습니다.

## 재검증 명령

```powershell
python -m pytest -q
python -m compileall -q src scripts
python scripts/validate_results.py  # 본인의 허가된 시장 자료로 만든 data/private 필요
python scripts/verify_outputs.py   # 공개 산출물 검사; private가 있으면 추가 재계산
```

최종 보고서와 HTML의 연결은 파일 해시로 확인합니다. 원문 수정이나 분석 재실행 이후에는 README·HTML·결과 PPT를 함께 다시 생성해야 합니다.
